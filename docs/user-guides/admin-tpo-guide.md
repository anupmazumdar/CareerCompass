# Administrator & TPO Guide: TalentAI Platform

## Platform Governance & Academic Oversight
1. **Employer Approvals**: Review pending recruiter profiles and employer domain registrations.
2. **Skill Taxonomy Management**: Inspect canonical skills, aliases, and parent-child hierarchies.
3. **Campus Placement Analytics**: View college placement conversion rates, active recruiter partnerships, and department benchmarks.
4. **Audit Logging**: Monitor application stage updates, admin interventions, and security access logs.
